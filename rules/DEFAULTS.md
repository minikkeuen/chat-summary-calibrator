# 기본 표현 보정 규칙

- `regex_ko.csv`: 한국어 기본 규칙 39개, 기본 활성화.
- `regex_en.csv`: 영어 기본 규칙 35개, 기본 활성화.
- `regex_all.csv`: 위 두 파일을 합친 규칙 74개, 중복 적용 방지를 위해 기본 비활성화. 통합 파일을 사용하려면 한국어·영어 파일을 끄고 이 파일을 켭니다.

`_aggressive.csv` 파일은 기본 규칙과 배포 ZIP에서 제외합니다. 규칙 내용과 행 순서는 제공된 CSV를 그대로 사용합니다. `node build-package.mjs --rules-only`로 CSV 내용을 기본 설정에 반영하고, `node build-package.mjs`로 반영과 배포 ZIP 생성을 함께 수행합니다.

신규 설치와 규칙 목록이 비어 있는 이전 설정에 기본 파일 목록을 제공합니다. 기존 사용자 규칙이 있으면 해당 목록을 유지합니다. 기본 규칙을 삭제하거나 비활성화한 뒤 설정이 저장되면 다시 켜거나 추가하지 않습니다. **신규 요약 저장 전 보정** 스위치는 기존 값과 기본 꺼짐을 유지합니다. 기존 요약은 명시적인 일괄 보정으로만 수정합니다.
