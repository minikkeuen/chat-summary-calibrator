# 마리나라 기억 보정 (Chat Summary Calibrator) 0.6.8

Marinara Engine 2.5.1용 확장입니다. 채팅 요약을 수동·자동으로 만들고, 기억 검색 설정과 요약 표현을 관리합니다. 기존 Chat Summary 저장 기능을 그대로 사용합니다.

## 설치

1. Marinara의 **External Extensions**에서 배포 ZIP을 가져옵니다.
2. 요청되는 `full_page_access` 권한을 확인하고 승인합니다.
3. 상단바의 **Chat Summary 아이콘**을 눌러 **마리나라 기억 보정**을 엽니다.

별도 서버 설치는 필요하지 않습니다.

## 요약 만들기

1. **모델 Connection**을 선택합니다.
2. 자동 요약을 사용하려면 **주기**를 설정하고 **현재 채팅 자동 요약**을 켭니다. 기본 주기는 **5 assistant 턴**입니다.
3. 수동으로 요약하려면 관리 화면의 수동 요약 기능을 사용합니다.

자동 요약은 **사용자가 다음 메시지를 전송할 때**, 이전 대화에 쌓인 assistant 메시지 수를 기준으로 실행됩니다. 사용자 메시지는 턴 수에 포함하지 않습니다. 자동 요약을 켜면 중복 생성을 피하도록 해당 채팅의 Engine 기본 자동 요약을 끄고, 해제할 때 이전 설정 복원을 시도합니다.

**요약 고급 설정**에서는 다음을 조정할 수 있습니다.

- **이전 요약 참고**: 최근 요약을 몇 개 참고할지 설정합니다(기본 3개).
- **오버랩**: 직전 대화 일부를 참고 문맥으로 포함합니다(기본 꺼짐).
- **중복 억제**: 기존 내용의 불필요한 반복을 줄입니다(기본 켜짐).
- **요약 프롬프트**: 요약 지침을 직접 수정하거나 기본값으로 되돌립니다.

## 기억 설정과 프리셋

**기억 설정**에서 Memory Recall, 요약된 메시지 숨김, 최근 원본 메시지 유지 수, **관련 요약 선택 주입(Semantic Retrieval)**을 조정합니다. 관련 요약 선택 주입을 켜면 최신 요약 수, 관련 과거 요약 수, 최소 유사도를 설정할 수 있습니다.

- **프리셋 설정 저장**: 현재 채팅의 기억 설정과 자동 요약 켜짐/꺼짐을 프리셋으로 저장합니다.
- **프리셋 적용**: 저장된 프리셋을 현재 채팅에 적용합니다.
- **새 채팅방에 자동 적용**: 켠 이후 새로 생성되는 RP 채팅에 프리셋을 적용합니다(기본 꺼짐). 기존 채팅과 분기 채팅에는 자동 적용하지 않습니다.

모델, 요약 주기, 고급 설정, 표현 보정 규칙은 채팅 간 공통 설정이며 프리셋에 포함되지 않습니다.

## 요약 표현 보정

요약에서 특정 표현을 자동으로 바꾸려면 **요약 표현 보정 → 표현 보정 설정**을 엽니다.

1. UTF-8 **CSV 또는 JSON 규칙 파일**을 준비합니다.
2. **규칙 파일 불러오기**로 등록하고 사용할 파일을 활성화합니다.
3. **미리보기 원문**에 예시 요약을 붙여 넣고 **보정 미리보기**로 결과를 확인합니다.
4. 새 요약에 자동 적용하려면 **신규 요약 저장 전 보정**을 켭니다(기본 꺼짐).

파일 이름은 `replace_ko.csv`(한국어 일반 치환), `replace_en.json`(영어 일반 치환), `regex_ko.csv`(한국어 정규식), `replace_all.csv`(언어 공통 치환)처럼 지정합니다. 언어 표시는 `ko`, `en`, `ja`, `zh`, `all`을 지원합니다.

CSV 예시:

```csv
찾을 표현,바꿀 표현
매우 강한 관심,관심
과도하게 강조했다,강조했다
```

JSON 예시:

```json
[
  { "찾을 표현": "매우 강한 관심", "바꿀 표현": "관심" }
]
```

일반 치환은 입력한 문자열과 정확히 일치하는 부분을 바꿉니다. 정규식은 패턴으로 일치 대상을 지정합니다. **규칙은 등록된 파일 순서와 파일 내부 행 순서대로 적용**되므로, 실제 요약에 사용하기 전에 미리보기로 확인하세요.

### 이미 저장된 요약 수정

1. **기존 요약 일괄 보정 → 기존 요약 불러오기**를 누릅니다.
2. 수정할 요약을 선택하고 **선택 요약 미리보기**를 실행합니다.
3. 원문과 변경 결과를 확인한 뒤 **변경 N개 승인·적용**을 누릅니다.

미리보기만으로는 저장되지 않습니다. 기존 요약 일괄 보정은 **신규 요약 저장 전 보정**이 꺼져 있어도 선택한 규칙으로 실행할 수 있습니다. 수정 중 일부 항목이 실패하거나 **확인 필요**로 표시되면 저장 상태를 확인한 뒤 다시 진행하세요.

## 알아둘 점

- 자동 요약은 **브라우저에서 확장이 실행 중일 때만** 작동합니다. 빈 입력으로 계속 생성하거나 일반 입력창 외 경로로 전송한 경우에는 자동 요약이 실행되지 않을 수 있습니다.
- 이미 저장된 요약은 새 규칙을 등록해도 자동 수정되지 않습니다. **기존 요약 일괄 보정**을 직접 실행해야 합니다.
- 최근 원본 메시지 유지 수를 바꿔도 기존에 숨겨진 메시지가 즉시 다시 계산되지는 않습니다.
- Engine 설정 화면을 이미 열어 두었다면 변경 사항 확인을 위해 새로고침이 필요할 수 있습니다.
- 확장을 비활성화하거나 제거할 때 자동 요약 설정 복원이 실패했다면 해당 채팅의 **Engine 자동 요약 설정**을 직접 확인하세요.

구현 세부사항, API, 제한 조건 및 검증 내용은 [개발·기술 참고](TECHNICAL-NOTES.md)를 확인하세요.
